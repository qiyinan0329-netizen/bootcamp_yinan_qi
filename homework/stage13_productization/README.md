# Regression Model Project

## Overview
Predict target values using a simple linear regression model.

## Requirements
- Python 3.10+
- Libraries: see `requirements.txt`

## How to Run
1. Train model: Run the training script to generate the trained model file model/model.pkl
2. Launch dashboard: `streamlit run app_streamlit.py`

## Files
- `model/model.pkl` : Saved trained model
- `app_streamlit.py` : Streamlit dashboard
